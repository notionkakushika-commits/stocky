# Stocky — 日用品在庫管理アプリ

洗剤・日用品をカテゴリと残量(個数)で管理するPWA。FreshlyのGitHub Pages配信パターンと同じ手順で公開できます。

## カテゴリ構成

- **洗濯**: 洗濯洗剤 / 柔軟剤 / 漂白剤 / 衣類用ハイター
- **キッチン**: 食器用洗剤 / 食洗機洗剤 / スポンジ / ラップ / アルミホイル
- **掃除**: 浴室用洗剤 / トイレ用洗剤 / 住居用クリーナー全般
- **バス・身体ケア**: シャンプー / コンディショナー / ボディソープ / ハンドソープ / 歯ブラシ / 歯磨き粉 / 固形石鹸
- **衛生用品**: (小カテゴリーなし、商品名のみで自由登録)
- **紙製品**: トイレットペーパー / ティッシュ / キッチンペーパー
- **その他**: ゴミ袋 / その他消耗品

## 機能

- 写真(任意・1枚) + 商品名 + 大カテゴリ + 小カテゴリ + 残量(個数)
- ダッシュボード: カテゴリチップでフィルタ、並び順を切替 (残量少ない順 / 多い順 / カテゴリ順 / 更新順)
- 行ごとに **±ボタン** で残量を1ずつ調整、**修正**で項目編集、**消去**で削除
- 残量バッジ色: 1個以下=赤、2個=橙、3個以上=通常
- IndexedDBに保存、エクスポート(JSON)で書き出し可

## デプロイ手順 (Freshlyと同じ)

1. Githubでpublicリポジトリを新規作成 (例: `Stocky`)
2. このフォルダの**中身全部**をリポジトリのrootへアップロード
3. Settings → Pages → Source: `Deploy from a branch`, Branch: `main` / `/(root)` → Save
4. 1〜2分後に `https://<username>.github.io/Stocky/` のURLが発行される
5. iPhoneのSafariでそのURLを開き、共有→「ホーム画面に追加」

## 注意

- カメラはHTTPS経由でないと起動しません (GitHub PagesはHTTPS)
- 写真は最大幅1024pxに自動縮小して保存
- IndexedDBに保存。Safariの「Webサイトデータを削除」で消えます
